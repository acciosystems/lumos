# Cadeia lógica

Problema social identificado
↓
Pesquisas mostram baixa confiança + necessidade de informação
↓
Literatura mostra relação entre transparência e confiança
↓
Doações físicas apresentam problemas de coordenação
↓
Redes sociais são boas para mobilização, mas não necessariamente para gerenciamento
↓
Nossa Causa centraliza informações + acompanhamento + transparência + organização
↓
Logo, existe fundamentação para a criação da solução.
